HOSPITAL MANAGEMENT SYSTEM - PROJECT FLOW

1. ADMIN WORKFLOW
-----------------
[ START ]
    |
    v
[ Admin Login ] -> (Credentials: admin@hospital.com / admin123)
    |
    +---> [ Dashboard Overview ]
    |       |-- View Total Doctors
    |       |-- View Total Patients
    |       |-- View Total Ambulance Drivers
    |
    +---> [ Manage Doctors ]
    |       |-- View Pending Approvals
    |       |-- Approve / Reject New Doctor Registrations
    |       |-- Delete Doctors
    |
    +---> [ Manage Ambulance Drivers ]
            |-- View Driver List
            |-- Monitor Status

2. DOCTOR WORKFLOW
------------------
[ START ]
    |
    v
[ Registration ] -> (Submit Name, Specialization, License, etc.)
    |
    v
[ Wait for Approval ] -> (Admin must approve account)
    |
    v
[ Login ]
    |
    +---> [ Dashboard ]
    |       |-- View Stats (Patients, Appointments)
    |
    +---> [ My Appointments ]
    |       |-- View Upcoming Appointments
    |       |-- Mark as Completed
    |
    +---> [ Patient Care ]
            |-- Search Patient by ID/Name
            |-- Request Profile Access (if restricted)
            |-- Submit Medical Report (Diagnosis, Prescription)

3. PATIENT WORKFLOW
-------------------
[ START ]
    |
    v
[ Registration / Login ]
    |
    +---> [ Dashboard ]
    |       |-- View Health Stats
    |
    +---> [ Book Appointment ]
    |       |-- Browse Doctors
    |       |-- Select Date/Time
    |       |-- Confirm Booking
    |
    +---> [ Emergency ]
    |       |-- Click "SOS" / "Call Ambulance"
    |       |-- Select Available Driver
    |       |-- View Live Driver Location (GPS)
    |
    +---> [ Medical Records ]
    |       |-- View Past Reports from Doctors
    |       |-- Download PDF Reports
    |
    +---> [ Privacy ]
            |-- View Access Requests from Doctors
            |-- Approve / Deny Profile Access

4. AMBULANCE DRIVER WORKFLOW
----------------------------
[ START ]
    |
    v
[ Login ]
    |
    v
[ Set Status ] -> (Go Online / Offline)
    |
    v
[ Wait for Request ] <---|
    |                    |
    +---> [ Receive Alert ] (Socket.io Real-time)
    |       |-- View Patient Name & Location
    |       |-- Accept Request
    |
    v
[ tracking ] -> (Broadcast GPS Location to Patient)

5. SYSTEM INTERCONNECTIONS
--------------------------
(Patient) Book Appointment  ----->  (Doctor) View Appointment
(Doctor) Submit Report      ----->  (Patient) View Report
(Patient) Request Access    ----->  (Doctor) View Profile
(Patient) Request Ambulance ----->  (Driver) Receive Alert
(Admin) Approve User        ----->  (Doctor/Driver) Login Enabled
